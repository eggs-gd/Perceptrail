# Perceptrail

**Perceptrail** — це self-hosted фотогалерея нового покоління, яка дозволяє користувачам взаємодіяти з великою бібліотекою фотографій через динамічну та гнучку систему навігації. Замість традиційних альбомів і каталогів, **Perceptrail** пропонує безперервну подорож через ваші фото, дозволяючи переглядати їх із різних перспектив і аспектів, таких як люди, геолокації, об'єкти, камери та інші метадані, які додаються за допомогою штучного інтелекту.

Ключова концепція полягає в тому, щоб надати нескінченний спосіб взаємодії з контентом. Переміщуючись між схожими фотографіями, користувачі можуть бачити їх у нових ракурсах, обираючи точки огляду за допомогою системи плагінів, яку ми називаємо **Perceptors**. 

**Perceptors** — це модульна система, яка закладається "з нуля", дозволяючи інтегрувати різні плагіни для аналізу, пошуку та взаємодії з фото. Плагіни можуть додавати нові критерії навігації, такі як фільтри за геотегами, обличчями, об'єктами, моделями камер і багато іншого.

## Основні особливості

- Безкінечний перехід між фотографіями на основі схожості або метаданих.
- Навігація за людьми, геолокаціями, об'єктами, камерами, та іншими критеріями.
- Потужна система плагінів **Perceptors** для додаткових функцій навігації та аналізу.
- Можливість інтеграції з AI/ML для розпізнавання і аналізу контенту.

## Технології

- **Frontend**: [Svelte](https://svelte.dev/) з використанням **IndexDB** для локального зберігання і швидкої взаємодії.
- **Backend**: Реалізовано на [Go](https://go.dev/), для зберігання даних використовується **PostgreSQL**.
- **ML Backend**: (у розробці) Ймовірно, буде реалізовано на Go або Python з кастомною структурою даних для зберігання результатів машинного навчання.

## Можливості

- Інтерактивне відображення та редагування метаданих кожного елемента.
- Фільтрування за різними критеріями, що залежить від встановлених плагінів **Perceptors**.
- Підтримка групових операцій для масового редагування даних.
